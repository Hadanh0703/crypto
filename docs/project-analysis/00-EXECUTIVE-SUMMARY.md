# Executive Summary

**Kết luận:** đây là dashboard phân tích thị trường crypto, lấy Binance Futures klines và CoinDesk news, lưu raw vào MinIO, dữ liệu có cấu trúc vào ClickHouse, tính nến 5 phút/chỉ báo/tín hiệu rồi phục vụ qua NestJS và React (`VERIFIED_IN_CODE`). Repository thực tế là sáu project cạnh nhau, không có Git root chung. Có hai đường ingestion: collector → Kafka → Spark và backend worker → ClickHouse trực tiếp. Kubernetes hiện triển khai collector worker, Spark stream, batch định kỳ, API và frontend; backend worker trực tiếp không xuất hiện trong manifest (`VERIFIED_IN_CODE`).

Sản phẩm có Overview, Chart, News, News Impact và Chatbot. Kafka có bốn topic được khai báo nhưng collector chỉ phát `klines-1m` và `news`. Spark raw bảo tồn payload và Kafka metadata ở Parquet, phân vùng theo topic/ngày/giờ. Spark structured sink explode event và ghi `news`, `future_kline_1m` vào ClickHouse. Batch đọc raw Parquet, gom 1m thành 5m, tính SMA20/SMA50, RSI14 Wilder, Bollinger và volume spike, rồi ghi ba bảng phân tích. Backend truy vấn ClickHouse và chatbot dùng OpenAI function calling để gọi chính REST API nội bộ. Không thấy RAG, embeddings, vector database hay model ML được train (`NOT_IMPLEMENTED`).

Mức sẵn sàng production còn thấp: không có Secret manifests trong repo, nhiều ConfigMap được tham chiếu nhưng không định nghĩa; ClickHouse dùng tag `latest`; Kafka một broker/replication 1; Spark và batch chưa có test; collector có race khi release Redis lock; batch có fallback sang Binance Spot/static mock và có thể che lỗi MinIO; insert signal không idempotent. Các manifests chỉ chứng minh cấu hình, không chứng minh cluster đã chạy (`CONFIGURED_NOT_EXECUTED`).
